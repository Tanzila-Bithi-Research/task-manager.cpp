📝 project-5: File-Based Task Manager

​🚀 Key Features:

​Data Persistence: Unlike previous projects, this one saves data into a .txt file, so your tasks remain even after closing the program.

​Append Mode: New tasks are added to the end of the file without overwriting existing ones.
​Read/Write Logic: Demonstrates how to write data to and read data from external storage.

​🧠 Concepts Learned:

​File Streams: Using ofstream for writing and ifstream for reading files.
​Persistent Storage: Understanding how to store data outside of the program's memory.
​Buffer Management: Handling cin.ignore() to ensure smooth user input.

​🛠️ How to Use:

​Run the program.
​Select 1 to Add a task. This will create/update a file named tasks.txt.
​Select 2 to View all tasks saved in that file.
​The data will stay saved even if you restart your computer!
